##Contexto | Problema social

	Hoje se vive em uma era onde a desinformação é extremamente difundida pela sociedade. Mídias sociais e algoritmos especializados facilitam a circulação dessa desinformação. O site de busca mais utilizado no mundo com mais de 90% de adoção, de maneira que é sinônimo com a própria internet, coloca como a primeira opção para o usuário sua própria IA que mastiga conhecimentos de toda a internet e coloca uma barreira entre o usuário e as fontes primárias que é ótimo para conseguir informações de modo rápido porém péssimo para garantir a procedência dessas informações.










Mesmo antes da adoção de agentes de IA como uma fonte de busca de conhecimento parafraseando para simplificar os conhecimentos, o Google já manipulava seus algoritmos para priorizar companhias que pagavam mais pela exposição, criando uma economia de atenção e transformando uma ferramenta de conhecimento em uma extensão da propaganda que a televisão já proporcionava antes deste.



###Conceito | Farol

Num geral isso apresenta problemas sociais mas nenhum é maior do que a perda de um espaço que incentiva a busca e curiosidade por estudos. Num mundo onde o tempo é cada vez mais valorizado porém cada vez menos utilizado de maneira que ajude no crescimento pessoal, o Farol busca reacender essa chama em pessoas que desejam estudar para conseguir realmente entender os assuntos abordados ao invés de somente receber informações desenhadas para satisfazer um desejo imediato. Farol é uma plataforma feita com estudantes em mente porém idealizada para que todos os que desejam acesso à educação possam ser conectados com material de confiança necessário para sua jornada.

###Provas e Simulados

A plataforma também conta com uma secção onde uma o usuário pode ver e realizar uma seleção de provas e simulados disponíveis publicamente, que também colocam referências em cada questão para que o aluno que desejar poder não somente testar o conhecimento com a pergunta mas também ter acesso a referências que ajudam a entender o conteúdo e os conceitos da questão. 



###Inclusão de conteúdo

A inclusão de conteúdo seria feita por meio do time da plataforma em um primeiro momento mas com os usuários teria um sistema de inclusão de conteúdo pelos próprios usuários que podem adicionar fontes confiáveis que seriam verificadas por um número de usuários e se necessário pelos moderadores da plataforma de acordo com a secção de moderação.





###Moderação

###Moderação Pública

	Usuários podem optar por auxiliar na moderação da plataforma, os usuários que escolherem auxiliar estarão disponíveis para receber notificações em uma aba de moderação onde conteúdo incluído por outros usuários é mostrado para 100 usuários que visitam regularmente a categoria referente ao conteúdo. Se uma categoria X tem menos do que 100 usuários que a plataforma vê como capazes no assunto , a moderação é feita por moderadores da plataforma para qualquer conteúdo inserido no assunto. O conteúdo é aceito se tiver 80% de aprovação



Não existe nenhum incentivo a moderação para evitar que uma gamificação da plataforma promova comportamento indesejado onde usuários podem aceitar as aplicações de conteúdo somente para ganhar pontos sem realmente checar se é relevante e confiável.


Ao mesmo tempo, um usuário que constantemente envia conteúdo confiável na plataforma recebe uma estampa de contribuidor confiável (visível ao usuário?) que diminui o número de pessoas necessárias para verificar o conteúdo antes de ser incluído. Da mesma maneira contribuidores não confiáveis (que tiverem um número de aceitação menor que 50% com pelo menos 3 contribuições fracassadas) ficam marcados no sistema (invisível ao usuário) para aumentar o número de aprovações. Os números de moderadores necessários assim como a quantidade de aprovações necessárias tem que ser facilmente modificados para conseguir regular o sistema.





###Moderação Interna da Plataforma

Última instância de moderação, revisar conteúdos reportados e verificar a confiança de conteúdos com poucos usuários aptos.
Funcionalidades não inclusas

Algumas funcionalidades foram planejadas mas ainda não implementadas pela natureza do projeto de curto prazo. A principal seria uma aba de registro de “Notas” que funcionariam de maneira similar as playlists do Youtube, porém para guardar e organizar os seus links para facilitar o estudo. ##Design

	O design é inspirado principalmente na página inicial do google um design limpo com um foco grande na pesquisa, sem muitos pontos de distração para uma experiência direcionada sem incentivos para tirar o foco do usuário. A intenção do site é diminuir o atrito, característico de mídias sociais que procura prender o usuário em suas plataformas através de uma corrente de informações incessante, para criar um espaço onde o usuário consiga focar nos seus estudos.




Outra grande inspiração são as apostilas escolares tanto na forma quanto na escolha de cores e como tratar diferentes materiais e criar essa distinção mental entre as disciplinas disponíveis. 

###Evitar Gamificação

Gamificação tem seu lugar no aprendizado quando usado de maneira correta. O brincar é uma parte vital no aprendizado de crianças. Porém empresas percebendo isso, utilizaram da natureza adicta humana para criar ambientes que usam aprendizado como fachada para um ambiente que preda nessa impulsividade e ansiedade para extrair recursos dos mais aficionados nessas plataformas. O Farol não adota medidas de gamificação na sua filosofia de design para evitar não só que o usuário veja o estudo como uma forma de cumprir bônus diários mas também para evitar comprometer o sistema de auto moderação da plataforma garantindo que as pessoas não procurem atingir alguma meta abstrata só para conseguir uma estampa ou algo do tipo.

###Não é uma social media

	Pelo perfil de usuário da plataforma ser direcionado a estudantes, uma grande parte da base de uso seria menor de idade, por isso foi levado em consideração esse fato no momento de pensar em recursos que o site poderia ou não poderia ter. Por isso o nível de interação entre usuários é praticamente inexistente para não conectar crianças com indivíduos mal intencionados. Ainda existe uma possibilidade da inclusão de uma seção de comentários, mas isso está sendo discutido e pensado bastante dentro do grupo para uma criar de maneira responsável.

##JAVASCRIPT e REACT

O principal benefício da implementação do projeto em react foi a capacidade de reutilizar páginas inteiras so mapeando uma “base de dados” (improvisada) para conseguir criar múltiplas versões de uma mesma página somente trocando a informação que é vital para um projeto como esse que possui diversas páginas com uma mesma estrutura (Eg. as várias provas diferentes). Além disso a reutilização de componentes similares como os cards presentes na página de estudar e os na página provas também facilita muito na produção do código.
